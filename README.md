# Сайт писателя Василия Попкова

Сайт с каталогом книг, продажей EPUB, CRM и Telegram-ботом @PetyaVasechkinBot. Работает на Cloudflare Workers: `https://popkov-site.a-perevedencev.workers.dev`.

- `assets/` — сайт (`index.html`), CRM (`crm/`), обложки, политика конфиденциальности
- `src/` — воркер: API сайта и CRM, выдача EPUB по ссылкам, бот
- `migrations/` — схема базы D1
- `scripts/` — сборка страницы сайта из шаблона и данных
- `windows/` — «Развернуть сайт.bat» и «Обновить сайт.bat» для развёртывания с ПК

Пароль CRM, токен бота и прочие секреты в репозитории не хранятся: они задаются через `wrangler secret put` при развёртывании. Файлы EPUB тоже не хранятся — загружаются в R2 со своего компьютера.
