# Сайт писателя Василия Попкова

Сайт с каталогом книг, продажей электронных, печатных и аудиокниг, отрывками, песнями на стихи автора, CRM и Telegram-ботом @PetyaVasechkinBot. Работает на Cloudflare Workers: `https://popkov-site.a-perevedencev.workers.dev`.

- `src/home.html` — шаблон главной страницы; каталог, отрывки и песни подставляются сервером из базы (`src/render.js`)
- `assets/` — CRM (`crm/`), страница стихов (`stihi.html`), обложки, политика конфиденциальности
- `src/` — воркер: API сайта и CRM, выдача файлов по ссылкам, песни и фрагменты (`media.js`), бот
- `migrations/` — схема базы D1 (`0002_content.sql` — издания, отрывки, песни)
- `scripts/build_site.py` — сборка страницы стихов из `src/poems.json`

В CRM: «Каталог» — книги и их издания (электронное, печатное, аудио: цена у автора, ссылка на магазин, файл для покупателя, фрагмент), «Отрывки», «Песни» (аудиофайл или ссылка, текст, скачивание).
- `windows/` — «Развернуть сайт.bat» и «Обновить сайт.bat» для развёртывания с ПК

Пароль CRM, токен бота и прочие секреты в репозитории не хранятся: они задаются через `wrangler secret put` при развёртывании. Файлы книг и песен тоже не хранятся — они загружаются в хранилище R2 через CRM или со своего компьютера.
